# 📚 Library Management System

A menu-driven **Library Management System** developed in Python that demonstrates modular programming, CRUD operations, reusable functions, and JSON-based data persistence.

This project is part of the **python-playbook** repository, showcasing practical Python applications and problem-solving through real-world implementations.

---

## ✨ Features

- ➕ Add New Book
- 📋 Display All Books
- 🔍 Search Book by ID
- ✏️ Update Book Details
- 🗑️ Delete Book
- 💾 Save Data to JSON
- 📂 Load Data from JSON
- 📚 Update Copies for Existing Books
- 🖥️ Menu-Driven Command-Line Interface

---

## 🛠️ Technologies Used

- Python 3
- JSON
- Jupyter Notebook

## 🚀 How to Run


Navigate to the project

```bash
cd python-playbook/projects/library-management-system
```

Run

```bash
python library_management_system.py
```

or open

```
library_management_system.ipynb
```
