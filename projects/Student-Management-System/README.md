# 📚 Student Management System

A menu-driven **Student Management System** developed in Python that demonstrates modular programming, CRUD operations, and JSON-based data persistence.

This project is part of the **python-playbook** repository, which focuses on practical Python implementations and structured technical notebooks.

---

## ✨ Features

* ➕ Add Student
* 📋 Display Students
* 🔍 Search Student
* ✏️ Update Student
* 🗑️ Delete Student
* 💾 Save Student Records to JSON
* 📂 Load Student Records from JSON
* 🖥️ Menu-Driven Command-Line Interface
* ✅ Duplicate Roll Number Validation

---

## 🛠️ Technologies Used

* Python 3
* JSON
* Jupyter Notebook

## 🚀 How to Run

1. Clone the repository.

```bash
git clone <repository-url>
```

2. Navigate to the project directory.

```bash
cd python-playbook/projects/student-management-system
```

3. Run the Python script.

```bash
python student_management_system.py
```

Or open the Jupyter Notebook.

```text
student_management_system.ipynb
```
